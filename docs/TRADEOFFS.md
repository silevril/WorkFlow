# Компромиссы

## Что выбрано сознательно

- **Свой UI, не UI-kit.** ТЗ запрещает прятать учебную работу за готовой админкой. Tailwind + собственные компоненты.
- **postgres.js без ORM.** Схема обозрима, SQL видно на защите, нет скрытого слоя миграций-магии. Цена: руками маппить camelCase (делает `transform: postgres.camel`).
- **SSR для публичных страниц, SPA-like для консоли.** Cookie-auth и персональные данные не должны светиться в HTML постороннему. `routeRules` это фиксируют.
- **Файлы на диске.** Для учебного объёма S3 избыточен. В Docker том не подключён — вложения не переживают recreate контейнера app.
- **Undo статуса ограничен.** Обратный переход часто запрещён бизнес-правилами. Rollback приоритета — полный.

## Что осталось ограничением

- Нет отдельного object storage и CDN для вложений.
- SLA-уведомления «скоро истечёт» создаются при seed и при эскалации; фонового cron нет, чтобы не усложнять Docker.
- Demo URL преподавательский нужно задеплоить: локальный Docker закрывает запуск, но не публичный HTTPS.

## Если появится мобильный клиент

Бизнес-правила уже в `shared/` и API. Мобильному клиенту не нужно копировать Vue-компоненты — только контракт `/api/*`.
