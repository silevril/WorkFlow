# Change log уровней

Проект собран как финальный контур 1–9 в одном репозитории.

- Level 1: layouts, список/карточка, фильтры, empty/loading/error, 404, keyboard focus.
- Level 2: useAsyncData, URL-фильтры, debounce, retry, адаптер `adaptRequest`.
- Level 3: Pinia UI/Undo, optimistic priority + rollback, комментарии.
- Level 4: Nitro + PostgreSQL + session auth + server authorization.
- Level 5: unit tests, race/idempotency комментария, stale search abort, Playwright.
- Level 6: landing/FAQ/help/articles, sitemap, robots, routeRules, PERFORMANCE.md.
- Level 7: shared/server/app границы, ARCHITECTURE.md, ADR-lite.
- Level 8: SLA admin, escalated, attachments, notifications, analytics.
- Level 9: Docker Compose, README, demo accounts, CI, AI_USED.md.
